title: Community Adapters
---

Sometimes, you may wish to use Inertia with a server-side framework other than Laravel. The [Inertia protocol](/v3/core-concepts/the-protocol) is framework-agnostic, and the community maintains adapters for many languages and frameworks, such as Rails, Django, Phoenix, Go, and .NET.

The official [Laravel](https://laravel.com/) adapter is the [reference implementation](/v3/advanced/building-an-adapter#the-reference-implementation) of the protocol, so the examples in this documentation use Laravel. Each community adapter has its own documentation for installation and framework-specific APIs.

<Note>
  The Inertia core team does not maintain community adapters. Support for newer protocol features varies from adapter to adapter.
</Note>

A partial adapter implements the core protocol but lacks some newer features, such as once props, rescued deferred props, or shared prop keys for instant visits. An adapter for Inertia v2 does not work with the v3 client-side adapters.

## Listing Your Adapter

To list your adapter on this page, open a pull request against the [documentation repository](https://github.com/inertiajs/docs). Before you open the pull request, make sure that your adapter meets these requirements:

- It implements the [protocol](/v3/core-concepts/the-protocol) for a supported Inertia version.
- It documents its installation, root template, and shared data APIs.
- It states which Inertia version and protocol features it supports.
- It has an active maintainer and a release on your language's package registry.

The [building an adapter](/v3/advanced/building-an-adapter) guide lists the features of a complete adapter.
